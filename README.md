# 🇺🇸 Jonas Oliveira (English)

## 🚀 About Me
I am a hybrid professional focusing on **Quality Assurance (QA)**, **Test Automation**, and **Fullstack Software Development**. I have solid experience in developing modern test architectures and scalable web applications.

I work on high-impact projects, applying analytical rigor from database modeling and CI/CD integrations to rich frontend interfaces focused on user experience and security. *   **Technologies**: React (Vite), Node.js, Express, Socket.io, Puppeteer, SQLite, Glassmorphism CSS.
*   **Highlight**: Contains a WhatsApp bot integrated with a robust Puppeteer automation that quietly extracts daily statements from Mercado Pago and InfinitePay. Web dashboard powered by WebSockets for real-time Pix notifications and billing, featuring automatic daily cron jobs.

### ⚡ [Gerador de Grade Pro (Softcom Grid Automator)](https://github.com/jonas-oliveira-coder/gerador-de-grade)
*Intelligent product cataloging automation for the Softcom ecosystem.*
*   **Technologies**: React, Node.js, Express, Concurrently, Vite.
*   **Highlight**: High-performance administrative panel designed to drastically accelerate the creation, duplication, and management of physical product grids (size/color grids), completely replacing repetitive manual work.

### 🥋 [Academia Central - Portal & Management](https://github.com/jonas-oliveira-coder/academia-central)
*Integrated academic management and digital presence platform for Taekwondo.*
*   **Technologies**: React, Vite, Node.js, Express, QR Code Engine, Lazy Loading.
*   **Highlight**: Connects a modern public portal with a responsive layout to a robust administrative panel. Features a dynamic blog, optimized media gallery, and a secure **Digital Membership Card** system verified instantly via QR Code.

### 📱 [Preços Alagoas (Alagoas Prices)](https://github.com/jonas-oliveira-coder/precos_alagoas)
*Multiplatform application for intelligent price and fuel search.*
*   **Technologies**: React, HTML5/CSS3, Mobile integration.
*   **Highlight**: Application that consumes the public API of the "Economiza Alagoas" project by SEFAZ/AL. Allows real-time searches of products (via GTIN/EAN code) and fuels, comparing values to save money in the state of Alagoas.

### 🗺️ [Santifica.me](https://santifica.me.jonas.qzz.io/)
*Interactive study platform connecting knowledge and technology.*
*   **Technologies**: React, Vite, Quartz, Logseq Engine, Markdown, Graph Visualization.
*   **Highlight**: Project that organizes theological and technological content as an interactive **Knowledge Graph**. The backend processes notes exported directly in Markdown and builds a fluid visual connection map on the web interface.

### 🎮 [RetroArch Wrapper](https://github.com/jonas-oliveira-coder/retroarch-wrapper)
*Low-level system utility in C to bypass Steam co-op limitations.*
*   **Technologies**: C Language, Windows API, Steam Integration.
*   **Highlight**: Low-level wrapper acting as a ghost executable (`retroarch.exe`). It tricks Steam into believing the official RetroArch is running, enabling the **Steam Remote Play Together** feature for any local cooperative game that doesn't natively support it out of the box.
